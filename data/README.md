# Dataset

This folder contains the datasets used for the case study.

## Files

### 1. Smartphone Usage & Distraction Behaviour Survey
The original questionnaire response dataset collected through Google Forms.

It contains the initial responses collected for the study.

### 2. smartphone_distraction_synthetic
The expanded synthetic dataset used for the final analysis.

It contains 10,000 records based on the structure and variables of the original questionnaire dataset.
